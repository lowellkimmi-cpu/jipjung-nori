# 집중 놀이터

아이와 집에서 함께하는 놀이 13가지를 모은 웹 앱이에요.
**개인이 만든 무료 비영리 앱이에요.** 광고, 결제, 접속 분석 도구가 없어요.

## 들어 있는 놀이
숫자 찾기 · 윙윙 꽃밭 · 짝꿍 카드 · 불빛 순서 · 다른 그림 찾기 · 같은 모양 · 패턴 잇기 · 반쪽 그림 · 선 긋기 미로 · 이게 뭐야? · 누가 뭐 해요? · 몸으로 따라 해요! · 같이 놀아요!

## 사용법
1. 이 페이지 주소를 폰이나 태블릿 브라우저로 열어요.
2. 홈 화면에 추가하면 앱처럼 쓸 수 있어요. 자세한 기기별 방법은 `install.html` (앱 안 보호자 설정 → "이 기기" → "설치 방법 보기")에 있어요.
   - 아이폰(사파리): 공유 단추 → "홈 화면에 추가"
   - 안드로이드(크롬): 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
3. 한 번 열면 앱 파일이 기기에 저장돼서, 그다음부터는 인터넷이 없어도 열려요.
4. "누가 놀까요?"에서 별명으로 아이를 추가하고 놀이를 골라요. 아이 추가와 보호자 설정은 간단한 덧셈으로 어른 확인을 거쳐요.

## 개인정보 안내
- **저장하는 것**: 별명, 동물 그림과 색, 만 나이, 놀이 설정, 판마다의 놀이 기록. 실명·생년월일·사진·학교·위치는 받지 않아요.
- **저장하는 곳**: 그 기기의 브라우저 저장소(localStorage)에만 저장해요. 아이 정보와 기록은 이 기기 밖으로 보내지 않아요. 만든 사람은 아이 정보와 기록을 볼 수 없어요.
- **앱 파일 받기**: 앱 파일은 GitHub Pages에서 받아요. 이때 GitHub가 접속 기록(IP 주소 등)을 남길 수 있어요(GitHub 개인정보 처리방침을 따라요).
- **지우는 법**: 보호자 설정 → 아이 "고치기" → "이 아이와 기록 지우기", 또는 기록 보기 → "이 아이 기록 지우기". 브라우저의 사이트 데이터 지우기로도 모두 지워져요.
- 기록 내보내기 파일에는 실명을 쓰지 말고, 다른 사람과 공유하지 마세요.
- 검색엔진에 나오지 않도록 페이지에 noindex 표시를 해 두었어요.
- `photos/` 폴더에는 만든 사람이 직접 찍은 사물 사진만 넣어요(사람 얼굴·위치가 드러나는 사진은 넣지 않아요).

## 안내
- 집에서 함께하는 놀이예요. 짧게 놀고 쉬어요. 기록은 그날 컨디션에 따라 달라질 수 있어요.
- 발달이 걱정되면 전문가와 상담하세요.
